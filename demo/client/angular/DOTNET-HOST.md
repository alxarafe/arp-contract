# Integración de hosts de demostración

La integración .NET de ARP-DEMO-002 se amplía en ARP-DEMO-004 con un cliente común para .NET, Java y PHP.
Las instrucciones y el comportamiento vigente están en [MULTIRUNTIME-HOSTS.md](MULTIRUNTIME-HOSTS.md).

`bin/integration-dotnet` se conserva como alias de `bin/integration-multiruntime`; ahora ejecuta los tres hosts.
Ninguna de estas APIs de demostración constituye un transporte normativo de ARP.
